# E-commerce Data Cleaning, Analysis & Visualization with Excel

## 📌 Project Overview

This project is part of my **Data Analytics (DA) Module-End Assignment 1**. The main objective is to clean, transform, analyze, and visualize an E-commerce dataset using Excel or WPS Office.

As an aspiring Data Analyst, I am developing practical skills in data preparation, spreadsheet formulas, statistical analysis, data summarization, and visualization. This project demonstrates the process of transforming raw E-commerce data into a structured dataset that can be used to generate meaningful business insights.

## 🎯 Project Objectives

- Import and organize E-commerce data into structured tables.
- Identify and handle duplicate records and missing values.
- Correct inconsistent data, formatting errors, and data types.
- Remove irrelevant columns where necessary.
- Apply spreadsheet formulas for calculations and logical operations.
- Combine related tables using VLOOKUP or XLOOKUP.
- Perform descriptive statistical analysis.
- Summarize data using Pivot Tables.
- Create charts, PivotCharts, and an interactive dashboard.
- Present key findings and decisions in a concise report.

## 🛠️ Tools & Technologies

## 📂 Dataset Description

The project uses an E-commerce sales dataset containing sales transactions and related customer and product information.

Depending on the source dataset, the tables may include fields such as:

- Product ID and product details
- Customer ID and customer details
- Quantity sold
- Cost and other sales-related values
- Transaction information

The dataset is organized into related tables to support data cleaning, lookup operations, and analysis.

## 🔄 Project Workflow

### 1. Data Import and Organization

- Imported the dataset into spreadsheet worksheets.
- Reviewed the available tables, column names, and data types.
- Organized data into structured tables.
- Checked the consistency of column headings and formats.

### 2. Data Cleaning and Transformation

- Checked for duplicate records.
- Identified and handled missing values.
- Standardized inconsistent text entries.
- Checked Product IDs and Customer IDs for formatting inconsistencies.
- Corrected numeric and text data types where necessary.
- Removed irrelevant columns when appropriate.
- Validated the cleaned data before performing analysis.

**Objective:** Improve data quality and prepare reliable data for analysis.

### 3. Spreadsheet Formulas and Functions

Applied spreadsheet formulas to perform calculations, validation, and analysis.

| Function | Purpose |
|---|---|
| `SUM` | Calculate total values |
| `AVERAGE` | Calculate average values |
| `IF` | Apply logical conditions |
| `COUNTIF` | Count records matching specified criteria |
| `TEXT` | Format values consistently |
| `VLOOKUP` / `XLOOKUP` | Retrieve matching information from related tables |
| `MEDIAN` | Calculate the middle value |
| `MODE` | Identify the most frequently occurring value |
| `STDEV.S` | Calculate sample standard deviation |

The formulas are used according to the available columns and the requirements of the dataset.

### 4. Combining Tables Using Lookup Functions

Used VLOOKUP/XLOOKUP to connect related datasets through common identifiers, such as Product ID or Customer ID.

This process helps retrieve information from related tables and supports further sales analysis.

**Key learning:** Consistent ID formatting, correct lookup ranges, and validation of lookup results are essential when combining datasets.

### 5. Descriptive Statistical Analysis

Calculated descriptive statistics to understand the distribution and characteristics of numerical data.

The analysis includes:

- Mean
- Median
- Mode
- Standard deviation
- Minimum and maximum values
- Count of observations

These measures help summarize numerical data and identify patterns or unusual values.

### 6. Pivot Table Analysis

Created Pivot Tables to summarize data across relevant dimensions.

Potential analysis areas include:

- Sales by product
- Sales by category
- Sales by customer
- Quantity sold by product
- Cost and sales comparisons, where the necessary fields are available

Pivot Tables make it easier to compare groups and identify business patterns without manually calculating every summary.

### 7. Data Visualization and Dashboard

Created visualizations to communicate analytical findings clearly.

The project aims to include at least three chart types:

- **Bar Chart:** Compare products or categories.
- **Column Chart:** Compare sales or quantities across groups.
- **Pie Chart:** Show each category's contribution to a total.
- **PivotCharts:** Visualize summarized Pivot Table results.
- **Interactive Dashboard:** Combine key metrics and charts in one place.

Where supported, filters and slicers can be added to help users explore different parts of the dataset.

### 8. Reporting and Business Insights

Prepared a concise summary explaining the data cleaning decisions, analytical findings, and observations from the charts and Pivot Tables.

The final report should connect the analysis to actual results from the dataset rather than assumptions.
